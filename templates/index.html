How PhishShield AI Works

A multi-stage hybrid detection architecture combining Natural Language Processing, trained machine learning classifiers, and deep URL structural analysis.

1. NLP & Language Identification

Detects language (English, Hindi, Spanish, French) and extracts tokens, stop-words, urgency triggers, and psychological intimidation markers.

2. Deep URL Inspection

Extracts links and analyzes IP hostnames, URL shorteners, typosquatting/lookalike domains, excessive subdomains, and mismatched anchor text.

3. Machine Learning Classification

TF-IDF vectorizer + Multinomial Logistic Regression model scores probability distributions across Safe, Spam, and Phishing classes.

4. Composite Risk Scoring

Synthesizes all intelligence sources into an explainable 0–100 risk score categorized into Low, Medium, or High Risk with transparent breakdown.
